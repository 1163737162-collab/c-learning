## 这组代码要掌握什么

字符串排序要用strcmp比较内容，不能直接用数组名的大小比较；交换整个字符串用strcpy和临时字符数组。string_sort.c 保存了冒泡和选择两种写法，其中一份在注释中，便于对照。

字符串反转仍是对称位置交换。字符镜像替换则是同一位置的字符值改变，例如 `'A'+'Z'-ch` 将A映成Z。最长回文子串把每个字符或字符间隙作为中心，向两侧扩展，分别覆盖奇数长度与偶数长度。

## 关键写法或推演

```c
int odd = expand(str, n, i, i);
int even = expand(str, n, i, i + 1);
```

中心扩展每轮先确认 `left>=0` 和 `right<n`，再访问字符串并比较两端。
