## 这组代码要掌握什么

从最简单的及格判断，发展到多个整除条件的组合。if/else if 应先匹配最具体的情况，例如同时满足3、5、7，再判断只满足两个或一个。`&&` 表示同时满足，`||` 表示至少一个满足。

switch 的 case 标签对应具体整数值，每个分支通常用 break 防止继续执行后续 case。默认分支的关键字必须准确写成 default。

## 关键写法或推演

```c
if (ch >= '0' && ch <= '9') {
    printf("数字");
}
```
