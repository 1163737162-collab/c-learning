## 这组代码要掌握什么

这一日用逻辑表达式处理票数规则和闰年，用数字拆分识别三位水仙花数，用多个独立 if 处理三笔金额。多笔商品可以都触发费用，所以它们应分别判断；若改成 else if，就可能只处理其中一笔。

闰年规则：能被4整除且不能被100整除，或者能被400整除。月份天数还需要结合2月与大小月判断。`scanf("%d%c%d",...)` 中 `%c` 会读取紧接着的分隔字符，输入格式应与此设计一致。

## 关键写法或推演

```c
int leap = (year % 4 == 0 && year % 100 != 0)
           || year % 400 == 0;
```

## 归档时值得回看之处

- shopping_cost.c 的 `printf("%.2fn",sum);` 会额外输出字母n，若想换行应写 `printf("%.2f\n",sum);`。
- year.c 最后一个 else 会把未覆盖的月份也按30天处理；若题目允许无效月份，需要单独校验。水仙花数程序目前按三位数拆分，不能把该算法直接当作任意位数版本。
