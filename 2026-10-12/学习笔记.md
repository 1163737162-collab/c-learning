## 这组代码要掌握什么

程序从 `main` 开始执行，`#include <stdio.h>` 提供标准输入输出函数的声明。`printf("Hello, World!\n");` 中的 `\n` 表示换行，`return 0;` 表示正常结束 main。源文件 `.c` 与运行文件是两个东西，修改源码后需要重新编译。

## 关键写法或推演

```c
#include <stdio.h>
int main(void)
{
    printf("Hello, World!\n");
    return 0;
}
```
