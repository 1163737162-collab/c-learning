## 这组代码要掌握什么

这一天的核心是“先看运算数类型，再看变量类型”。`5/9` 两边都是整数，先算出0，再存入 double 也还是0；`5.0/9` 或 `5/9.0` 才进行浮点除法。`(double)(5/9)` 转换发生得太晚，`(double)5/9` 才能保留小数。

温度式 `(F-32)*5/9` 中 F 是 double，所以前面的乘积已经是浮点数；它与单独先计算 `5/9` 不同。读取 double 用 `%lf`，输出两位小数用 `%.2f`。

## 关键写法或推演

```c
double a = 5 / 9;          // 0
double b = 5.0 / 9;        // 约0.555556
double c = (double)5 / 9;  // 约0.555556
```
