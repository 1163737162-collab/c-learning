## 这组代码要掌握什么

数组适合先读入整组数据，再比较、交换和输出。find_min.c 同时保存值和下标，遇到并列最小值时用 >= 更新，所以会保留最后一个位置；若要求第一个位置，应只在严格更小时更新。

逆序用 `j` 与 `n-1-j` 配对，只换前一半。选择排序每轮找剩余区间最大值的下标，再与当前位交换，形成降序；这与今天7-10的方法一致。

## 关键写法或推演

```c
for (int j = 0; j < n / 2; j++) {
    int temp = arr[j];
    arr[j] = arr[n - 1 - j];
    arr[n - 1 - j] = temp;
}
```
