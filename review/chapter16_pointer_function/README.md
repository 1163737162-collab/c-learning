# 第 16 章　指针和函数

按鹏哥《第16章：指针和函数》17 页讲义整理。每道题都有自己的 C 文件，题目、自测示例和代码框架直接写在文件里。按 TODO 自己填写。

| 题号 | 这一题练什么 | 讲义页码 |
| --- | --- | --- |
| 01 | 定义函数指针并用两种方式调用 | 1–3 |
| 02 | 拆声明，用 typedef 给函数指针类型起名 | 4–6 |
| 03 | 在数组里存放函数指针 | 6–7 |
| 04 | 用转移表做计算器 | 7–10 |
| 05 | 用函数参数实现回调 | 10–12 |
| 06 | 用 qsort 排整数 | 12–14 |
| 07 | 用 qsort 排结构体 | 14–15 |
| 08 | 按字节交换两个对象 | 15–16 |
| 09 | 用冒泡排序实现通用排序 | 15–17 |
| 10 | 用同一个通用排序函数处理不同类型 | 15–17 |

在 VS Code 的终端里切到本文件夹，一次只编译一道题：

~~~sh
build_dir=$(mktemp -d /tmp/ch16-practice.XXXXXX)
clang -std=c17 -Wall -Wextra -Wpedantic 01_call_through_pointer.c -o "$build_dir/01"
"$build_dir/01"
~~~

换题时改掉源文件名和可执行文件名。框架里的 (void)变量 只是让编译器暂时不提示“未使用”。写完 TODO 后就可以删掉对应的占位行。框架能编译只说明它可以作为起点，写完后要用题目的示例核对输出。

建议先做 01～05，再做 06～07。08～10 是讲义的通用排序加餐。
