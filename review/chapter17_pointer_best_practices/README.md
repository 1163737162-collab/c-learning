# 第 17 章　指针的最佳实践

根据鹏哥的 [第 17 章原版讲义](第17章：指针的最佳实践.pdf) 整理。每道题是一个单独的 C 文件，题目、自测示例和代码框架都在文件里。按 TODO 自己填写。

| 题号 | 练习内容 | 讲义页码 |
| --- | --- | --- |
| 01 | 初始化并检查指针 | 1–2 |
| 02 | 保存分配起点，释放后置空 | 1–2 |
| 03 | 用 if 检查空指针 | 2–3 |
| 04 | 区分 if 和 assert，比较启用与禁用断言 | 3–4 |
| 05 | 区分 const 修饰指向的数据和指针本身 | 5–7 |
| 06 | 用 const 参数实现 my_strlen | 8 |
| 07 | 创建、复制和销毁带指针成员的结构体 | 8–9 |
| 08 | 把数组长度传给函数，检查下标范围 | 9 |
| 09 | 用调用者的数组保存函数生成的数据 | 9–10 |
| 10 | 用 typedef 简化回调声明 | 10 |

每道题都自带 main。从 VS Code 终端切到本目录，一次编译一道题：

~~~sh
build_dir=$(mktemp -d /tmp/ch17-practice.XXXXXX)
clang -std=c17 -Wall -Wextra -Wpedantic 01_initialize_pointer.c -o "$build_dir/01"
"$build_dir/01"
~~~

换题时改源文件名和输出名。框架里暂时用 (void)变量 消除“未使用变量”的提示，写好 TODO 之后可以删掉。做完后用文件里给的示例核对结果。
