# 指针到位运算：综合复习

这套题按顺序从简单到综合，共 11 题。每题都是独立的 C 文件，题目、示例和 TODO 都在文件中；没有完整答案。先自己写，写完再让我帮你检查。

| 题号 | 练习内容 |
| --- | --- |
| 01～03 | 指针与数组、函数参数、二级指针 |
| 04～05 | 字符串遍历、自己实现 strcpy |
| 06～08 | malloc、calloc、realloc、free |
| 09～10 | 结构体、结构体指针、指针成员 |
| 11 | 用 n & (n - 1) 统计二进制中 1 的个数 |

在 VS Code 打开本目录，在终端运行（以第一题为例）：

\`\`\`sh
clang -std=c17 -Wall -Wextra -Wpedantic 01_pointer_array.c -o /tmp/c_review_01
/tmp/c_review_01
\`\`\`

每题都有自己的 main，**一次只编译一个文件**，把命令中的文件名换成当前题目即可。默认代码中的 return 0 有时只是占位，不是答案；没填写 TODO 时输出可能为空或不符合示例。

内存题记得检查分配失败并释放申请得到的首地址。第 8 题扩容到 5 个元素指的是**总共 5 个**，不是在原来的 3 个之外再加 5 个。第 11 题使用 unsigned int，UINT_MAX 的答案是当前平台 unsigned int 的位数；不要假定所有机器都一样。
