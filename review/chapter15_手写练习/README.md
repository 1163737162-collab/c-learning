## 阅读讲义时的几个细节

- 第2页对`malloc(0)`的说法不够准确：零大小请求的行为取决于C标准版本和实现，练习只使用正大小。
- 第3页的数组版示例出现了未定义的`ptr`；课堂用意是对比数组与动态分配，应使用实际数组名。
- 四道笔试题原代码调用`strcpy`时未包含`<string.h>`；`printf(str)`还会把内容当作格式串。参考实现使用固定格式串。
- 经典题1、2、4均不能推断一个确定的输出；经典题3在分配成功等条件下可输出，但仍需释放内存并检查失败。
- 第12页的`int a[0]`是某些编译器扩展，标准C柔性数组成员使用`int a[]`。
- 第13页用`%d`打印`sizeof`并写死结构体大小为4，不具有可移植性；本练习用`%zu`并实际观察。
- 第14页的指针成员示例在第二次申请失败时还应释放已申请的结构体。
