## 怎么使用

- 每天先打开对应的学习笔记，再点表格中的代码链接。
- `编译产物/` 保存旧运行文件；修改源码后应重新编译，不要把旧运行结果当作新源码的结果。
- 每个C程序单独编译运行；不要一次把多个含main的源文件链接在一起。
- 2026-11-11的6-1至6-5是PTA函数题，需配合题目裁判程序。
- 历史笔记中“归档时值得回看之处”说明当前源码的静态问题或待核对条件，未自动修复源码，也未重新提交PTA。
- 输出文件使用相对路径时，文件位置取决于运行时的工作目录。
