## 这组代码要掌握什么

把多项式写成 f(x)，主程序只管理区间。端点函数值异号时，连续函数在区间内至少有一个零点；算中点后，保留仍然异号的一半。停止条件是区间宽度足够小。

本文件的多项式连续。异号条件是可用的存在性判断，但“端点不异号”本身不能对任意函数证明区间没有根；端点本身也可能就是根。

## 关键写法或推演

```c
mid = (m + n) / 2;
if (f(mid) == 0)
    break;              // 中点恰好是根，不能再丢掉这一点
if (f(m) * f(mid) < 0)
    n = mid;
else
    m = mid;
```

## 归档时值得回看之处

- 原源码没有检查 `f(mid)==0`。例如区间[1,3]的中点2恰好是根，但代码进入else令m=2，随后会趋向3而不是保留根。上面的复习片段补上了中点为根的停止判断，归档源码未修改。
- 现有代码只接受 `f(m)*f(n)<0`，会把端点本身为根的情况也放进“没有根”分支。
- mid 在 while 内才赋值；若初始异号区间宽度已经不大于0.00001，循环一次也不执行，后面输出mid会读取未初始化值。源码保持原样，复习时需要注意这个边界。
