### 变量已经声明后，只赋值

```c
int r = 0;
do {
    r = x % y;       // 不要再写 int r
    x = y;

} while (r != 0);
```

如果循环里面又写 `int r`，就创建了另一个变量。外面的 `r` 仍然为 0，循环只执行一次。

```c
double a = 1, b = 1;    // 同时声明两个变量
```

`double a=1; b=1;` 只声明了 a，b 如果此前没有声明，就不能使用。

## 3. 输入与输出：今天最值得记住的区别

### scanf 必须与地址对应的类型匹配

| 变量 | 输入格式 | 示例 |
|---|---|---|
| `int n` | `%d` | `scanf("%d", &n);` |
| `float price` | `%f` | `scanf("%f", &price);` |
| `double time` | `%lf` | `scanf("%lf", &time);` |
| `char ch` | `%c` | `scanf("%c", &ch);` |

`printf` 输出时，float 会提升为 double，两者都可用 `%f`。`%d` 用于 int；`%.0f` 不显示小数位，`%.2f` 保留两位，`%.3f` 保留三位。`%8d` 和 `%5d` 指最小输出宽度，默认右对齐，不是小数位数。

### 输入组数决定循环形式

- 只有一组：读取一次。
- 先给出组数 T：循环 T 次。
- 给出若干组，直到输入结束：读取成功就继续。

```c
while (scanf("%d %d %d %d", &n, &f1, &a, &b) == 4) {
    printf("%d\n", f(n, f1, a, b));
}
```

每轮先执行 scanf。返回 4 表示成功赋值四个变量；返回其他值，就不处理不完整数据。每组结果必须换行，否则 `4、6、3` 会连成 `463`。

### fgets 写在 if 里，仍然会执行读取

```c
if (fgets(a, sizeof(a), stdin) == NULL)
    return 0;
```

执行顺序：先读取并写入 a，再检查返回值。成功时返回数组首地址；读入任何字符之前就遇到输入结束，或发生读取错误时返回 NULL。只按回车能读到换行符，也算读取成功。

| 写法 | 含义 |
|---|---|
| `NULL` | 空指针，这里用于判断未读到输入或读取失败 |
| `'\0'` | 字符串结束标志 |
| `'0'` | 数字字符 0 |
| `' '` | 空格 |
| `'\n'` | 换行 |

## 4. 字符与字符串统计

数字字符指单个字符。`123` 的字符形式由 `'1'`、`'2'`、`'3'` 三个字符组成。判断单个字符：

```c
ch >= '0' && ch <= '9'
```

ASCII 常用范围：`'0'`～`'9'` 为 48～57，`'A'`～`'Z'` 为 65～90，`'a'`～`'z'` 为 97～122。数字字符编码连续，所以 `'7'-'0'` 等于 7。

字符串统计的正确顺序：先读取，再逐字符分类。不要先扫未初始化数组，也不要把整个数组容量当成字符串长度。

```c
int res[4] = {0};
for (int i = 0; a[i] != '\0' && a[i] != '\n'; i++) {
    // 字母、数字、空格、其他
}
```

字母判断包含 A/Z/a/z；数字判断包含 0/9。`fgets` 可能保留行末换行，本题不把该换行算作其他字符。空格要比较 `' '`，不是 `'\n'`。

## 5. 函数与二维数组：我今天真正理解的内容

### 声明、定义、调用

```c
float amount(float list[], int n, float min);  // 声明
float result = amount(list, n, min);          // 调用
```

声明要放在使用之前；可以放在 main 前面，不能插在 `int main()` 与它的 `{` 之间。定义和声明的参数名可以不同，但类型、个数、返回类型要匹配。

普通函数也可以调用另一个普通函数。例如标准差函数内部可调用平均值函数，不必把嵌套调用一直写在 main 中。今天归档的运动员代码保留了自己传入平均值的三参数版本；两种接口都能表达这个算法。

### 数组名、某一行、某一个元素

假设 `double arr[n][6];`：

| 传入表达式 | 表示什么 | 对应参数示例 |
|---|---|---|
| `arr` | 整个二维数组 | `double a[][6]` |
| `arr[i]` | 第 i 行，即一个运动员的六次成绩 | `double a[]` |
| `arr[i][j]` | 一次成绩 | `double x` |

调用 `average(arr[i], 6)` 后，函数里的 `a[j]` 对应外面的 `arr[i][j]`。数组传入的是地址，函数修改数组元素会影响原数组；不会复制整个数组。

### 成绩和下标分开

```c
int fast_id = 0;                        // 第几个人
double t = average(arr[fast_id], 6);     // 这个人的平均时间
```

下标必须是整数，平均值和标准差用 double。只保存最优下标也能选出获选者，输出时再算这个人的指标。保存最小值和下标也可以，但找到更小值时，两者必须一起更新。

### 7-3 判断素数

具体错误：主函数定义大写 N，却用小写 n 控制循环；scanf 后漏分号；Yes/No 后漏换行。isPrime 的试除思路正确。

```c
if (n < 2) return 0;
for (int i = 2; i <= n / i; i++) {
    if (n % i == 0) return 0;
}
return 1;
```

找到一个因数即可判非素数；必须全部检查完才能返回 1。检查到平方根即可，因为因数成对出现。正整数条件下 `i<=n/i` 可避免 `i*i` 溢出。

### 7-6 斐波那契数列

原始递归公式 `fib(n-1)+fib(n-2)` 数学逻辑正确，但会重复计算，n 到 60 时效率不足。循环保存相邻两项即可。

```text
c=a+b → a=b → b=c
```

临时变量 c 先保存和，再移动 a、b。n 为 1 或 2 时不进入从第3项开始的循环，直接返回 b=1。实际还出现过 `double a=1;b=1;` 的声明错误。

### 7-8 商场优惠

min 是参加优惠的总金额门槛，不是最低商品价。最低价另用 lowest 保存。

```text
求总金额，同时找最低价格

→ 只减去一件最低价商品
```

实际问题：第一行漏读门槛，把门槛当成了第一件价格；float 用 `%d` 读取；sum 用 int 丢失小数；无条件减最低价；漏件数判断；`>` 漏掉等于门槛；把价格变量 lowest 当成数组下标；lowst/lowest 拼写不一致。

`float lowest=list[0]` 只是初始化，后面仍需遍历更新：

```c
if (list[i] < lowest)
    lowest = list[i];
```

“保存最低价本身”与“保存最低价下标”都可行，写法必须统一。我最后学会用同一个循环求总价和最低价，并把应付金额计算放进 amount。

### 7-9 运动员选拔

保留自己的思路：二维数组保存所有成绩，分别计算指标，用下标记录最优运动员。两个指标可能由不同的人获得，因此各有一个下标。

标准差公式是本题的样本标准差：平方差之和除以 `count-1` 再开平方。六次成绩的分母为 5。数组测验的方差题则按该题要求除以 n，不能混用。

```c
sqrt(sum / (count - 1))
// 或 pow(sum / (count - 1), 1.0 / 2)
```

`1/2` 是整数除法，等于 0；`1.0/2` 才是 0.5。`sum/count-1` 表示除完再减1，与 `sum/(count-1)` 不同。

### 7-12 矩阵转置

转置就是行列互换，`a[i][j]` 与 `a[j][i]` 交换。原地交换适用于本题的4×4方阵。

```text
原来的第一行 1 2 3 4 → 转置后的第一列
主对角线 a[0][0]、a[1][1]、a[2][2]、a[3][3] 不变
```

实际问题：for 用逗号分隔；遍历整个矩阵导致每对元素交换两次又恢复；改循环时误写 `int j=j+1`，读了未初始化的 j。

```c
for (int i = 0; i < 4; i++) {
    for (int j = i + 1; j < 4; j++) {
        int temp = a[i][j];
        a[i][j] = a[j][i];
        a[j][i] = temp;
    }
}
```

j 从 i+1 开始，保证只交换对角线上方的每一对位置一次。不是 j+1，因为当前行号是 i。

7-14 的递归公式写对了：`f(1)=f1`，`f(n)=a*f(n-1)+b`。实际问题是只读一组，而题目要求读若干行；随后加了循环却没有换行，结果连在一起。按 scanf 返回值循环读取，每组输出后换行即可。

### 7-15 递归逆序输出整数

`n%10` 取个位，`n/10` 去掉个位。先输出个位，再递归处理剩余部分。

```text
12345：输出5 → 1234：输出4 → 123：输出3 → 12：输出2 → 1：输出1并停止
```

实际问题：声明 int、定义 void 不一致；`printf("n")` 输出字母 n；结束条件写 `n>0 && n<9` 漏掉 9，导致 `9→0→0→…`，不断输出而超时。正整数输入下，一位数条件可直接写 `n<10`。今天归档最终版为 `n>0 && n<10`，在题目规定的正整数输入下同样能停止。

不要照搬上一题的多组输入：本题输入格式明确只读一个正整数。换行放在 main 调用 reverse 后一次即可。

### 数组测验的三题

- **查找整数**：遍历数组，匹配时输出下标并设置找到标记，break 退出；循环结束后未找到再输出 `Not Found`。不能在第一个不匹配处就断定整个数组不存在目标。
- **数字字符统计**：用 fgets 读整行，逐字符检查 `'0'`～`'9'`，计数器从0开始。
- **计算方差**：先求均值，再累加每个数与均值之差的平方，最后按该题要求除以 n，输出两位小数。
